# Cost & Metrics System - COMPLETE

**Date**: 2025-11-28  
**Status**: Implemented and ready for testing

## Summary

Added comprehensive cost tracking and metrics display with real-time feedback and detailed summaries. Renamed "sequences" to "flows" for better branding alignment.

## What Was Implemented

### 1. Pricing Data Module

**File**: `agent/data/model-pricing.mjs`

- Pricing table for all supported models (OpenAI, Anthropic planned)
- Pricing in USD per 1M tokens (input/output separate)
- Context window sizes
- Helper functions: `getCost()`, `getContextWindow()`, `getContextPercent()`

### 2. Config Pricing Overrides

**File**: `agent/core/config-loader.mjs`

Users can override pricing in `flow.config.mjs`:

```javascript
pricing: {
	overrides: {
		'gpt-4o': { 
			input: 2.00,            // Custom rate
			output: 8.00,
			context_window: 128000 
		},
	},
},
```

## Benefits

### For Users

1. **Cost Transparency**: See exactly what each agent costs
2. **Model Comparison**: Compare costs between gpt-4o vs gpt-4o-mini
3. **Optimization Insights**: High output tokens? Agent is verbose. High input? Reading too much context.
4. **Budget Planning**: "This feature cost $0.15 to develop and test"

### For Development

1. **Relative Costs**: "Flow A costs 3x more than Flow B"
2. **No exact precision needed**: Estimates are good enough for comparison
3. **User Control**: Override pricing if needed
4. **Future-proof**: Easy to add new models to pricing table

## Migration Notes

### Old Config → New Config

Old (`sequences`):
```javascript
export default {
	sequences: {
		development: { ... }
	}
}
```

New (`flows`):
```javascript
export default {
	flows: {
		development: { ... }
	}
}
```

**Backward Compatible**: Old configs with `sequences` still work (merged into `flows`).

### CLI Flag

- Old: `flow run --sequence development "task"`
- New: `flow run --flow development "task"`
- Both work (--sequence deprecated but functional)
