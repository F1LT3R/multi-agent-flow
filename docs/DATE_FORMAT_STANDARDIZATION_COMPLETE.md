# Date Format Standardization - Complete ✅

## Summary
Successfully standardized all dated files in the system to use `YYYY-MM-DD_HH-MM-SS` format with underscores as separators between date, time, and metadata components. This improves visual readability while maintaining date-first ordering for easy sorting.

## Format Specification

**Date/Time Format**: `YYYY-MM-DD_HH-MM-SS` (underscore between date and time, hyphens within each)

**Complete Filename Formats**:
- **Trace files**: `YYYY-MM-DD_HH-MM-SS_AGENT-NAME_rN-tN.md`
- **Checkpoint files**: `YYYY-MM-DD_HH-MM-SS_run_HASH.json`
- **Snapshot directories**: `YYYY-MM-DD_HH-MM-SS/`
- **Report files**: `YYYY-MM-DD_HH-MM-SS_REPORT_rN.md`

## Changes Made

### 1. Trace Files
**File**: `agent/core/trace-recorder.mjs`
- **Old format**: `2025-11-27-07-36-35-WRITE_USER_STORIES-r1-t1.md` (all hyphens)
- **New format**: `2025-11-27_07-36-35_WRITE_USER_STORIES_r1-t1.md` (underscores separate components)
- **Implementation**:
```javascript
const datePart = [
    now.getFullYear(),
    String(now.getMonth() + 1).padStart(2, '0'),
    String(now.getDate()).padStart(2, '0')
].join('-')

const timePart = [
    String(now.getHours()).padStart(2, '0'),
    String(now.getMinutes()).padStart(2, '0'),
    String(now.getSeconds()).padStart(2, '0')
].join('-')

const filename = `${datePart}_${timePart}_${agentName}_r${flowRun}-t${turn}.md`
```

### 2. Checkpoint Files
**File**: `agent/core/checkpoint-manager.mjs`
- **Old format**: `run-2025-11-27-07-45-04-264-729c1b08.json`
- **New format**: `2025-11-27_07-45-04_run_729c1b08.json`
- **Implementation**: Date-first with underscore separators between timestamp, "run", and hash
- **Note**: The 8-character hash (e.g., `729c1b08`) is generated by `crypto.randomBytes(4).toString('hex')` for uniqueness

### 3. Snapshot Directories
**File**: `agent/core/snapshot-manager.mjs`
- **Old format**: `.flow/snapshots/2025-11-27-07-42-48/` (all hyphens)
- **New format**: `.flow/snapshots/2025-11-27_07-42-48/` (underscore between date and time)
- **Implementation**: Same date/time split with underscore separator

### 4. Report Agent Instructions
**File**: `templates/REPORT.md`
- Updated instructions to generate report filenames with the new format
- **New format**: `2025-11-27_15-30-45_REPORT_r1.md`
- Agents are now instructed to use underscore separators between components

## Benefits

1. **Visual Clarity**: Date and time are visually separated by underscore
   ```bash
   ls -1 .flow/logs/traces/
   2025-11-27_07-36-35_WRITE_USER_STORIES_r1-t1.md
   2025-11-27_07-37-12_GENERATE_CODE_r1-t1.md
   2025-11-27_07-38-45_PLAN_TESTS_r1-t1.md
   ```

2. **Metadata Separation**: Underscores clearly separate timestamp from metadata
   - Date: `2025-11-27` (easy to scan)
   - Time: `07-36-35` (distinct from date)
   - Agent: `WRITE_USER_STORIES` (clearly separated)
   - Run info: `r1-t1` (grouped together)

3. **Maintains Sorting**: Date-first approach preserved, so `ls` still shows chronological order

4. **Consistent Pattern**: All dated files follow same `YYYY-MM-DD_HH-MM-SS_metadata` structure
   - Traces: `YYYY-MM-DD_HH-MM-SS_AGENT_rN-tN.md`
   - Checkpoints: `YYYY-MM-DD_HH-MM-SS_run_HASH.json`
   - Snapshots: `YYYY-MM-DD_HH-MM-SS/`
   - Reports: `YYYY-MM-DD_HH-MM-SS_REPORT_rN.md`

5. **Easy Parsing**: The format is predictable and can be easily extracted with regex:
   ```javascript
   /(\d{4}-\d{2}-\d{2})_(\d{2}-\d{2}-\d{2})/
   ```
