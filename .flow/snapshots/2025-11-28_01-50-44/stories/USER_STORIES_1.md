## High Level Goal
Create a simple script that logs 'Hello World' to the console.

## User Stories
- As a user, I want to run a script that outputs 'Hello World' to the console, so that I can verify the script is functioning correctly.

## Acceptance Criteria
- [ ] The script should be named `hello.js`.
- [ ] Running the script should output 'Hello World' to the console.
- [ ] The output should be exactly 'Hello World' with no additional characters or lines.

## Edge Cases
- Ensure that the script runs without error in a standard JavaScript environment.
- The script should handle being run multiple times without any change in behavior.
