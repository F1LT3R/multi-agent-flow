## High Level Goal
Create a simple calculator with an add function.

## User Stories
- As a user, I want a calculator that can add two numbers, so that I can quickly compute their sum.

## Acceptance Criteria
- [ ] A function named `add` should exist.
- [ ] The `add` function should take two numeric inputs.
- [ ] The `add` function should return the sum of the two inputs.
- [ ] The function should handle both integer and floating-point numbers.
- [ ] Input validation should ensure that both inputs are numbers; otherwise, an error should be returned.

## Edge Cases
- Handle cases where the inputs are not numbers (e.g., strings or null).
- Consider precision issues with floating-point arithmetic.
- Ensure the function works with negative numbers and zero.
